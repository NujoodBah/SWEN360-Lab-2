# SWEN360-Lab-2

## Project Idea 
This will be a simple application that aims to help NASA during a space mission, it will act as a simple checklist for the mission before its launch. Users are meant to check off the specific stuff listed (fuel, crew etc) before launching, and once the list is complete the app will make an announcement "You are Ready for Launch!".
This will help display just how much effort and planning goes into launching a space mission, and will allow students to get first hand experience on the preparation required for a mission to take place.

## Technologies and tools used 
HTML, JavaScript, C++
GitHub was used for project management 
Sublime text editor 

## How to run the project
Download this respiratory 
Open the project folder
Double-click index.html to open it in your browser.
Click on the checkboxes you completed up until you have completed every task written on the list
When all the tasks are checked, a message saying "You are Ready for Launch!" will appear.
